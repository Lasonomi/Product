# BLACKTASTE

Experimental Americano brand website — a cinematic, interactive frontend portfolio project.

## Requirements
- Node.js 20.9 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Production build
```bash
npm run build
npm run start
```

## Features
- Responsive editorial layout
- GSAP ScrollTrigger pinned product storytelling
- Custom desktop cursor with contextual labels
- Product selection interactions
- Mobile-specific reduced motion and layout
- `prefers-reduced-motion` support

## Customize
- Edit product content in `src/app/page.tsx`.
- Change palette, typography, layout, and animations in `src/app/globals.css`.
- Replace the remote Unsplash photo URLs in `src/app/page.tsx` with your own licensed product photography before publishing.
- Update the Instagram and contact destinations in the footer when you have real links.

This is a portfolio concept. Product descriptions and prices are illustrative placeholders, not claims about a real business.
